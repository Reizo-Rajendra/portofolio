Halo! 👋 Selamat datang di **Reizo's Village**. 

Ini portofolio interaktifku yang kubuat dengan konsep desa RPG 2D. Kamu bisa jalan-jalan keliling desa pakai keyboard (**WASD**), menikmati musik 16-bit santai (yang otomatis ganti pas malam), ngelus kucing, ngasih makan bebek di kolam, dan masuk ke bangunan-bangunan untuk lihat hasil karyaku!

### 🗺️ Tempat yang Bisa Dikunjungi:
- 🏡 **Home**: Kenalan denganku, cek foto profil, dan perjalanan sebagai Ketua Ekstrakurikuler Software Engineering Snapandev SMKN 8 Semarang.
- 🖼️ **Gallery**: Koleksi proyek unggulan (*Megantara 3D WebGL, POLANITAS Platform AI Inklusif, AI Gesture Recognition, Vintage Christmas Photobooth, Zears Hub*).
- 🛠️ **Workshop**: Senjata koding & tools yang biasa kupakai (*Svelte, React, Next.js, Node.js, Supabase, Tailwind, Python*).
- 🕊️ **Pigeon Coop**: Kirim surat online langsung ke emailku via burung merpati (didukung Resend API).

## 🚀 Cara Menjalankan di Localhost

### 1. Clone Repositori
```bash
git clone https://github.com/Reizo-Rajendra/portofolio.git
cd portofolio
```

### 2. Install Dependensi
```bash
npm install
```

### 3. Konfigurasi Lingkungan (Opsional)
Buat file `.env` di root folder jika ingin pakai Resend API sungguhan:
```env
RESEND_API_KEY=re_xxxxxxxxxxxxxxxxxxxx
```
*(Catatan: Tanpa API key pun sistem otomatis beralih ke mode simulasi cerdas, jadi form surat tetap bisa dicoba lancar).*

### 4. Jalankan Dev Server
```bash
npm run dev
```
Buka browser dan buka link ini:  
👉 **[http://localhost:3000](http://localhost:3000)**

---

## 🛠️ Build untuk Produksi

```bash
# Build produksi
npm run build

# Preview hasil build
npm run preview
```
Hasil build super ringan (~132 KB) akan tersimpan di folder `dist/`.

## ⚡ Highlight Teknis Singkat
- **Zero-Lag Loading**: Peta SVG desa dioptimasi dari 9.5 MB jadi 733 KB (150x lebih cepat terbuka).
- **Auto-Pause Canvas**: Kalau lagi buka dialog atau pindah tab, animasi canvas 60 FPS otomatis istirahat biar hemat baterai & RAM.
- **Prosedural Web Audio**: Musik 16-bit disintesis langsung lewat browser tanpa download file mp3 berat.
